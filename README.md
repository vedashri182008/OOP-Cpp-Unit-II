## 💻 Programs

This repository contains **16 Code Book programs** based on inheritance and related Object-Oriented Programming concepts.

### 01. Basic Single Inheritance
Demonstrates single inheritance using a base class and a derived class.

### 02. Protected Member Access
Demonstrates how a derived class can access a protected member of the base class.

### 03. Public vs Private Inheritance
Demonstrates the difference between public and private inheritance and their effect on accessibility.

### 04. Multilevel Inheritance
Demonstrates a three-level inheritance hierarchy using Person, Employee and Manager.

### 05. Hierarchical Inheritance
Demonstrates hierarchical inheritance where multiple derived classes inherit from a common base class.

### 06. Multiple Inheritance
Demonstrates multiple inheritance using two base classes for academic and sports records.

### 07. Multiple-Inheritance Ambiguity
Demonstrates how to resolve ambiguity in multiple inheritance using the scope-resolution operator.

### 08. Constructor and Destructor Order
Demonstrates the order of constructor and destructor execution in inheritance.

### 09. Parameterized Base Constructor
Demonstrates initialization of a parameterized base class constructor using an initializer list.

### 10. Function Overriding
Demonstrates function overriding using virtual and override functions.

### 11. Abstract Class
Demonstrates an abstract class using a pure virtual function and derived classes.

### 12. Virtual Base Class and Diamond Inheritance
Demonstrates the use of a virtual base class to solve ambiguity in diamond inheritance.

### 13. Friend Class
Demonstrates how a friend class can access private data of another class.

### 14. Nested Class
Demonstrates the creation and use of a class defined inside another class.

### 15. Vehicle Rental System
Implements an inheritance-based vehicle rental system using virtual functions and overriding.

### 16. Employee Payroll System
Implements an employee payroll system using an abstract base class, inheritance and function overriding.
